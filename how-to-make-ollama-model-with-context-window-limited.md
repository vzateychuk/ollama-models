# Как собрать модель Ollama с заданным контекстным окном и ограничением по токенам

## Описать модель в Modelfile

```bash
FROM granite4.2:3b
PARAMETER num_ctx 32768
PARAMETER num_predict 4096
```

Это опишет использование gemma4:e4b с окном в 16k и `max_tokens`= 4k (отвечает за максимальную длину ответа модели)

## Создать модель

```bash
ollama create granite4.2:3b-32k -f granite4.2:3b-32k.Modelfile
ollama create omnicoder-2-9b-32k -f omnicoder-2-9b-32k.Modelfile


```

Команда создаст модель с контекстным окном нужного размера

## Запустить в Ollama

```bash
ollama run gemma4:e4b-16k
```

## Ньансы

1. Даже если контекстное окно задано в 64k, при использовании Ollama не будет использовать его подставляя по умолчанию свое значение 2К
Поэтому рекомендуется явно прописать команду использовать все окно прмр

```
/set parameter num_ctx 65536
```

Как проверить: 

```
ollama ps
```

в поле `CONTEXT` должно быть **64К**

2. Ollama автоматически выгружает из памяти модель если ей некоторое время не пользоваться.

Как запретить модели выгружаться: можно изменить таймер с помощью системной переменной OLLAMA_KEEP_ALIVE, например: `OLLAMA_KEEP_ALIVE=1h`

Если надо насильно выгрузить из памяти модель Ollama, есть два варианта действий:

    Если вы хотите продолжить диалог позже, но память нужна прямо сейчас: Оставляете окно с чатом открытым, открываете новую вкладку терминала и вводите там `ollama stop gemma4:e4b-64k`. Модель выгрузится из видеопамяти. Когда вы вернетесь в первое окно и напишете новое сообщение, Ollama просто загрузит модель обратно.

    Если вы уже закончили общение: В окне чата пишете `/bye` или нажимаете Ctrl+D. Вы выйдете из чата в обычную командную строку Linux. После этого прямо в этом же окне можете ввести ollama stop gemma4:e4b-64k, чтобы не ждать 10 минут, пока она выгрузится сама.
